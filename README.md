# 造物岛（Maker Island）

一个面向小学三年级孩子的浏览器 3D 建模闯关原型。孩子从世界地图进入任务，在游戏故事中一次学习一个操作，通过动手建造、即时检查和自由改造逐步掌握空间拆解与设计思维。

## 当前版本

当前版本包含 3 个世界、12 个主线关卡，以及家庭云端档案：

- 地图一次只展示当前世界的 4 关，完成上一世界后再解锁下一世界。
- 主线依次训练形状拆解、移动、缩放、旋转、对齐、精确尺寸、复制、挖孔、壁厚、打印检查、任务规划和综合设计。
- 每关只显示当前步骤所需工具，并提供 6 秒演示、三级提示、自动结果检查和同本领变式挑战。
- 通关依据最终模型状态；操作记录只用于过程证据和明确要求的三步计划。
- 儿童端使用完成、精准、独立三个徽章；家长端显示 60/20/10/10 能力记录，第 12 关支持 40 分人工点评。
- 第 9～12 关可导出可编辑工程、STL、作品图和过程记录。
- 家长创建或打开家庭私密入口，孩子只填昵称；作品、进度与点评存入 Cloudflare D1，支持跨设备继续。
- 本地缓存与待上传队列支持断网编辑；版本冲突会停止覆盖并提供备份下载。

当前版本定位为“儿童 3D 创意能力训练 + 可选比赛模拟”，不是任何赛事的官方课程。暂不包含多人互动、排行榜、邮件注册或 R2 文件存储。工程、STL 和图片仍由浏览器导出，D1 保存可编辑模型 JSON。

## 运行要求

- Node.js 24.15 LTS（推荐）；测试工具也支持 22.22.2 LTS 或 26 及以上版本
- npm
- 推荐使用近期版本的 Chrome、Edge 或 Safari，以及带滚轮的鼠标

正式建模建议使用电脑或横屏平板；手机更适合查看地图，不适合精确拖动。

## 本地运行

首次拉取项目后安装锁定版本的依赖：

```bash
npm ci
```

初始化本地数据库后启动开发环境（只写本机模拟数据库，不会修改线上数据库）：

```bash
npm run db:migrate:local
npm run dev
```

终端会显示访问地址。开发环境同时运行前端页面和本地 Cloudflare Workers 运行时，`/api/health` 可用于检查 Worker 是否正常响应。

## 检查与构建

运行自动测试：

```bash
npm test
```

实际 D1 API 验收（先在另一个终端运行 `npm run dev -- --port 5183 --strictPort`）：

```bash
npm run test:cloud
```

这个脚本仅接受 localhost 地址，会在本地测试数据库创建合成家庭，验证独立会话恢复、同名家庭隔离、模型读写、重试幂等和冲突拒绝，不连接生产数据库。可传入其他本地端口：`npm run test:cloud -- http://127.0.0.1:5173`。

执行前端与 Worker 类型检查并生成 Cloudflare 部署产物：

```bash
npm run build
```

使用接近线上 Cloudflare Workers 的本地运行时预览构建结果：

```bash
npm run preview
```

`preview` 会先重新构建项目。Cloudflare Vite 插件会在 `dist/` 中生成浏览器资源、Worker 包和部署所需的输出配置；不要在输入用的 `wrangler.jsonc` 中手工填写 `assets.directory`。

发版前可以只检查部署包、不上传到 Cloudflare：

```bash
npx wrangler deploy --dry-run
```

请先至少执行过一次 `npm run build`，确保 Wrangler 能读取插件生成的输出配置。

## 部署到 Cloudflare

本项目使用 Cloudflare Workers Static Assets，不使用旧式 Pages Functions。第一次部署前，在本机登录自己的 Cloudflare 账号：

```bash
npx wrangler login
npx wrangler whoami
```

项目已经绑定数据库 `e49d9833-7f47-447f-861c-e62f9cd2628c`，绑定名称为 `DB`。使用这个数据库所属的 Cloudflare 账号；无需新建数据库、R2、KV，也无需手填数据库密码或 `SESSION_SECRET`。

首次上线必须先执行线上建表，再部署代码：

```bash
npm run db:migrate:remote
npm run deploy
```

该命令会先运行完整构建，再由 Wrangler 使用 Cloudflare Vite 插件生成的输出配置上传前端资源和 Worker。它会真实创建或更新名为 `maker-island` 的 Worker；升级现有站点时保留这个名称，仅在需要另建独立站点时修改 `wrangler.jsonc` 的 `name`。

`db:migrate:remote` 将 `migrations/` 中尚未执行的数据库结构变更应用到上面的真实数据库；这里的 migration 是建表/升级表结构，不是导入旧浏览器数据。仅有数据库 UUID 不等于有访问权限；未登录时不能执行线上建表或部署。CI 可以使用受限的 `CLOUDFLARE_API_TOKEN` 和 `CLOUDFLARE_ACCOUNT_ID`，令牌需要目标账号的 D1 与 Workers 部署相关权限，只应保存在 CI 的加密变量中。不要提交令牌。

如果使用 Cloudflare 的 Git 自动部署，构建命令使用 `npm run build`，部署命令使用 `npm run db:migrate:remote && npx wrangler deploy`，并确保构建身份有访问该 D1 的权限。不要让预览分支对生产数据库执行结构变更或保存测试数据；预览应配置独立数据库。手动部署时不必额外在控制台重复绑定，Wrangler 会通过配置绑定 `DB`。

部署后用同一个站点域名访问：先创建家庭，保存私密入口，再输入昵称。在另一台设备打开该入口、输入相同昵称，检查模型是否一致。`/api/health` 用于检查 API 服务；它不能替代真实读写验收。静态资源和前端路由由 Cloudflare 处理，只有 `/api/*` 会优先进入 Worker。

## 数据与隐私边界

当前版本采用家庭共享入口，而不是个人密码账号：

- 家庭入口是随机生成的 256 位密钥，放在链接的 `#family=…` 片段中；页面接收后立即清除地址栏中的密钥，通过同源 API 建立 HttpOnly 会话。D1 只保存入口和会话密钥的哈希；原入口只在创建时返回，并在本设备保留供家长复制。
- 拿到家庭入口的人可以查看、打开和修改这个家庭的所有用户档案。昵称不是密码，同家庭同名即同一档案，不同家庭同名互不相通。不要公开分享入口或填写儿童真实姓名、学校、联系方式。
- 用户名支持 1～16 个中文、英文字母、数字和下划线，忽略首尾空格、英文大小写与全半角差异。
- 学习进度、作品、操作记录、用时和家长点评会上传到 D1；作品 JSON 分关存储，进度与作品在一个事务中保存，服务端校验家庭权限、输入大小、档案版本和幂等写入标识。
- 浏览器缓存使用全新 `maker-island-cloud-profile-v1:<家庭编号>:<用户编号>` 命名空间，旧本机档案不会导入、上传或删除。云端从全新档案开始。
- 本机立即保存待同步草稿，网络写入约 2 秒合并一次，连续编辑最多约 10 秒触发；断网后显示“等待同步”，打开此档案时恢复队列并重试。关闭网页后不会在后台联网；其他未打开档案的待上传内容要重新选择该名字后继续同步。
- 切换用户前等待本机持久保存；断网但已落盘可以切换，本机存储失败或冲突则阻止切换。多设备冲突不自动覆盖，先下载当前备份，再明确选择重新载入云端。备份包含本机版本和可用的冲突版本，目前不提供自动导入备份工具。
- 更换设备前请确认“已同步到云端”。清除浏览器数据会删除尚未上传的草稿及本机保留的入口；已经上传的数据仍在 D1，需要原家庭链接才能恢复。丢失所有入口副本后没有邮箱找回功能，目前也没有自助入口撤销/轮换或家庭删除界面。
- API 不公开列出家庭，拒绝跨家庭访问；有同源检查、私密响应禁用缓存、输入限制和基本限流。家庭密钥不是防止同家庭成员查看档案的个人权限系统，本机缓存也不是加密保险箱。
- 未加入第三方广告、行为分析或聊天功能。Cloudflare 仍会处理正常请求所需的 IP 地址、请求头等技术信息。

面向儿童公开发布前，应按实际地区与运营主体完善家长同意、正式隐私说明、密钥撤销和数据删除流程。当前适合受邀家庭试用。不要把家庭入口、会话密钥或部署令牌贴进公开 issue、日志或前端 `VITE_*` 变量。

## Cloudflare 配置说明

- `vite.config.ts`：同时启用 React 与官方 Cloudflare Vite 插件。
- `wrangler.jsonc`：启用 SPA 回退，并使用 `run_worker_first: ["/api/*"]` 明确分离 API 与静态资源路由。
- `worker/index.ts`：家庭会话、用户档案与 D1 读写 API。
- `migrations/0001_cloud_profiles.sql`：家庭、会话、用户、作品、写入回执和限流表，以及事务版本保护。
- `src/CloudProfileHost.tsx`：家庭入口及用户切换；`src/cloudProfiles.ts` / `src/cloudWriter.ts`：云端通信、本地缓存和同步队列。
- `src/progress.ts`：课程进度计算；旧本机存储辅助函数保留供历史测试使用，不再由主界面调用。
